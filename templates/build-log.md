# Build log entry format

Append entries to the `## Build log` section of an idea file. Newest at the
bottom.

```markdown
### YYYY-MM-DD

**Goal:** what you set out to do in this session.

**Did:**
- commands run, config changed, versions pinned

**Broke:**
- what went wrong, and the actual error text if it was cryptic

**Fixed by:**
- what resolved it

**Next:** where to pick up.
```

The `Broke` / `Fixed by` pair is the reason this file exists. Anything you had
to search for once, you will search for again.
